Forecast how many GTA VI players earn each trophy in week one: for every PlayStation 5 trophy, five quantiles of its earn rate on Exophase at the target date. A single stdlib-only Python program (`main.py`) reads a case file and writes the forecast. The model anticipates Exophase's refreshes: a completely flat history means the page is stale and a refresh is pending, so the last rate is diluted ~6x; once the history moves, each trophy's logit rate is fitted against log-time and extrapolated to the target.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
